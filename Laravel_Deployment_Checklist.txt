Laravel Deployment Checklist (PHP 8.3 + Nginx)
Deployment Steps:

**Pull latest code**:

git pull

Install Composer dependencies:
composer install --no-dev --optimize-autoloader

**Run database migrations**:
php artisan migrate --force

**Publish uploaded media files**:

The admin image edit forms and API media URLs use the public disk at
`/storage/...`. Create the symbolic link on every deployment (or after a fresh
server setup):

php artisan storage:link

Verify that `public/storage` exists and that an uploaded image URL such as
`https://admin.nagpurmart.in/storage/...` does not return 404. Also ensure
`APP_URL=https://admin.nagpurmart.in` is set before clearing the config cache.

**Set Gemini model if needed**:
GEMINI_MODEL=gemini-3.5-flash
GEMINI_TIMEOUT=120

**Upload size settings (images are validated by Laravel at 10 MB):**

The deployed document root must include `public/.user.ini`, which sets PHP's
transport limits to `upload_max_filesize=20M` and `post_max_size=25M`.
In the Nginx `server` block for this application, set:

client_max_body_size 25M;

Verify the active limits and Nginx configuration on the VPS:

php -i | grep -E 'upload_max_filesize|post_max_size|max_file_uploads'
sudo nginx -T | grep client_max_body_size

**Clear and rebuild Laravel caches:**
php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan cache:clear

**Restart PHP-FPM:**
sudo systemctl restart php8.3-fpm

**Reload Nginx:**
sudo systemctl reload nginx

**Quick Deployment Commands:**
git pull
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan config:clear
php artisan route:clear
php artisan view:clear
php artisan cache:clear 
sudo systemctl restart php8.3-fpm
sudo systemctl reload nginx

**Useful Log Commands**
● Laravel: tail -f storage/logs/laravel.log
● Nginx: sudo tail -f /var/log/nginx/error.log
● PHP-FPM: sudo journalctl -u php8.3-fpm -f

**Check Service Status**
sudo systemctl status php8.3-fpm --no-pager
sudo systemctl status nginx --no-pager
